## 4. Beginner AI Scaffolding & Glossary Reference Plan

In accordance with the instructional mandate, the modular curriculum will apply the following scaffolding standard for all newly introduced AI concepts across Phase 06:

| Acronym / AI Concept | Full Definition | Beginner-Level AI Mental Model | Senior Systems Engineering Parallel |
|---|---|---|---|
| **Evals** | Continuous Model Evaluations | Automated tests that score probabilistic AI outputs against deterministic rubrics, reference answers, or operational SLAs. | Automated integration and regression test suites in CI/CD pipelines (e.g., JUnit, pytest, Playwright). |
| **LLM-as-a-Judge** | Large Language Model as an Evaluator | Using a highly capable model (e.g. Claude 3.7 or GPT-4o) with an explicit rubric to grade the quality, accuracy, or safety of another model's output. | An automated code review bot (e.g. SonarQube or linter) analyzing code against predefined quality rules. |
| **G-Eval** | Generation Evaluation with Large Language Models | A prompt-based evaluation framework that forces the evaluator LLM to generate explicit Chain-of-Thought (CoT) reasoning before assigning a score. | An automated code review requiring detailed architectural comments before signing off on a pull request. |
| **CoT** | Chain-of-Thought Prompting | Instructing a language model to articulate intermediate reasoning steps before arriving at a final conclusion or verdict. | A step-by-step execution trace or verbose stack trace showing the exact path taken to compute a result. |
| **NLI** | Natural Language Inference | An NLP technique where a model determines whether a premise sentence logically entails, contradicts, or is neutral to a hypothesis sentence. | An assertion library verifying that runtime output adheres to interface preconditions and postconditions. |
| **MMD** | Maximum Mean Discrepancy | A statistical distance metric that measures whether two sets of multidimensional embeddings come from the same probability distribution. | A network traffic distribution shift monitor comparing current packet length histograms against baseline averages. |
| **PSI** | Population Stability Index | A mathematical metric measuring how much a variable's distribution has shifted between a reference baseline dataset and current production traffic. | A traffic distribution anomaly detector comparing current request payload distributions against baseline production metrics. |
| **TTFT** | Time To First Token | The elapsed duration between dispatching a prompt and receiving the very first token in the streaming response. | Server Time to First Byte (TTFB) in HTTP/network requests. |
| **TPS** | Tokens Per Second | The generation velocity of the model, measured as output tokens produced per second after streaming begins. | Network throughput (e.g., megabytes per second or requests per second). |
| **ITL** | Inter-Token Latency | The elapsed time between consecutive streamed tokens during autoregressive generation. | Packet jitter / network packet inter-arrival time in streaming media protocols. |
| **RAGAS** | Retrieval-Augmented Generation Assessment | A standardized framework for evaluating RAG pipelines across Faithfulness, Answer Relevance, and Context Precision without requiring human ground truth. | An automated API contract verifier checking that database query results match client response payloads. |
