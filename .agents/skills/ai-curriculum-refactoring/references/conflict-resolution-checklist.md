# Report Conflict Resolution Checklist

Use this checklist when audit, research, or curriculum findings conflict.

## Resolution Checklist

* [ ] **Identify the conflict** — repository state, external fact, or curriculum decision?
* [ ] **Verify evidence** — inspect repository files for current-state claims; verify current technical claims using authoritative sources.
* [ ] **Classify the conflict**:

  * `NO_CONFLICT`
  * `COMPLEMENTARY`
  * `DIFFERENT_SCOPE`
  * `OUTDATED_INFORMATION`
  * `TRUE_CONFLICT`
  * `INSUFFICIENT_EVIDENCE`
* [ ] **Separate evidence from recommendations** — reports inform the decision; they do not determine it automatically.
* [ ] **Check prerequisites** — can the learner understand the topic at this point?
* [ ] **Check phase purpose** — does the topic support the phase learning outcome?
* [ ] **Check duplication** — is it already covered or better suited to another phase?
* [ ] **Check durability** — durable engineering concept or temporary/tool-specific trend?
* [ ] **Check cognitive load** — will adding it overload the lesson or phase?
* [ ] **Prefer restructuring before deletion** — simplify, merge, move, defer, or reference before removing valuable knowledge.
* [ ] **Choose an explicit action**:

  * `ADD`
  * `UPDATE`
  * `MERGE`
  * `MOVE`
  * `SIMPLIFY`
  * `DEFER`
  * `REFERENCE_ONLY`
  * `REJECT`
* [ ] **Record meaningful conflicts** — evidence, decision, reasoning, confidence, and impact.
* [ ] **Do not hide uncertainty** — use `HIGH`, `MEDIUM`, or `LOW` confidence where appropriate.

## Decision Priority

When conflicts remain, prioritize:

**Learning correctness → Prerequisites → Curriculum coherence → Technical accuracy → Durable knowledge → Current relevance → Conciseness → Tool/framework coverage**

## Core Rule

> **Verify → Classify → Check prerequisites → Check phase purpose → Check duplication → Assess durability → Decide → Record**

The Architect should make the final curriculum decision based on the **complete learning journey**, not by mechanically following either report.
